Your worksheet is in the queue

  • Every product is broken into its ingredients and matched to a food category. Large worksheets can take a while.
  • You'll get a .zip attachment from “Food Impact Processor”. If it doesn't show up, check your spam folder.

How it works

  1. AI reads each product description and estimates its main ingredients and their share of its weight.
  2. Each ingredient is matched to one of about 125 food categories.
  3. Weights are multiplied by per-category impact factors and added up.

What you'll get

  • Impact totals by category in US units (lb, gal, sq ft) and in metric units (kg, L, m²).
  • Category matches for every ingredient, so you can check them.
  • Ingredient breakdowns for every product, with estimated weights.
Preparing a file by hand

The uploader renames columns for you. If you'd rather format the CSV yourself, rename the headers as shown and add the layout code (type01, type02 or type03) in the first column of a new row under your last item.

type01: quantity and unit together

  • Product column → product
  • Quantity column → product_weight
productproduct_weight
Harissa Paste (Tunisian) 40z EA JAR80.000 OZ

type02: separate total weight

  • Item description → product, total weight → product_weight, quantity shipped → qty
  • Unit column (kg, lbs…) → unit. If there isn't one, add an empty column called unit. Weights are then treated as pounds.
  • Delete any “Total” rows at the bottom.
productItem #qtyproduct_weightunit
MILK WHOLE $4/1$ GAL *RG*77820132

type03: weight in the description

  • Item description → product, quantity sold → qty, stock unit → unit
  • Delete the “Grand Total” row if there is one.
productunitqty
CHEDDAR CLOTHBOUND AGED CABOT 30 LB MCLB19
